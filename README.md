# DigitalNest AI Store

A responsive static storefront for DigitalNest AI.

## Included
- Homepage / hero section
- Product catalogue
- Category filters
- Shopping cart
- Demo checkout flow
- Newsletter form
- FAQ
- Mobile responsive layout
- South African Rand pricing

## Run locally
Open `index.html` in a browser.

## Before going live
Connect a real payment provider and secure server-side checkout/digital delivery. Replace the sample products in `script.js` with your real products and prices.

Suggested production additions:
- PayFast / Peach Payments / Stripe
- Customer account or email delivery
- Secure file storage for downloads
- Analytics
- Domain + HTTPS
- Privacy policy, terms and refund policy
